CampMonitor Alpha 10

UI-freeze field-trial build for Freenove FNK0103S / ESP32-WROOM-32E / ST7796 320x480 (landscape rotation 3).

Changes:
- Five SOC colour bands: red 0-19.99%, orange 20-39.99%, yellow 40-59.99%, blue 60-89.99%, green 90-100%.
- Battery SOC uses the standard card value font with a separate smaller percent sign.
- Charging lightning bolt inside the battery icon.
- Slow battery-icon flash below 20% SOC.
- Battery page Used Ah and Time Left display two decimal places.
- Time Left is displayed as decimal hours.
- Refined Alpha 10 splash screen.

The existing tall 68-pixel navigation bar and enlarged 480x320 widgets remain unchanged.
