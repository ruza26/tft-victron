CampMonitor Web Flasher

Install CampMonitor v1.5.5 on a compatible Freenove 4-inch ESP32 display directly from your browser. No Arduino IDE or compiling required.

Install CampMonitor

  1. Connect the display to this computer with USB.
  2. Click Install CampMonitor.
  3. Select the ESP32 serial port when prompted.
  4. Follow the installer until flashing is complete.
This browser does not support Web Serial. Try a current Chromium-based desktop browser. The flasher must be opened from the HTTPS GitHub Pages site.

Important

This installer is for the Freenove 4-inch ESP32 CampMonitor build. A fresh flash can erase previously saved device keys, settings and history if the installer erase option is selected.

After installation

On a new installation, CampMonitor automatically starts its setup Wi-Fi. Connect to the CampMonitor-xxxxxx network and open 192.168.4.1. From there you can add Victron devices and encryption keys, change the display heading, and later install OTA firmware updates. The maintenance Wi-Fi can also be started manually when you need it.
