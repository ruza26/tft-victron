# CampMonitor 3D Printed Enclosure

This folder contains the printable enclosure files for the supported Freenove 4-inch CampMonitor display.

## Files

- `case-bottom-plainv15.stl`
- `freenove back case (1).stl`

These two STL files are the enclosure parts currently supplied with the project.

## Printing notes

- Import the STL files into your preferred slicer.
- Check orientation and support requirements in the slicer before printing.
- Material, layer height, wall count and infill can be adjusted to suit your printer and installation.
- Print one of each part for a complete enclosure.
- Test-fit the display, RTC module and wiring before permanent installation.
- The enclosure is intended to remain serviceable so it can be opened again if a component needs replacement.

The enclosure was made around the Freenove 4-inch hardware used by CampMonitor. Fit on other display boards is not guaranteed.
